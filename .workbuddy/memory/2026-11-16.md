## 第四轮：垃圾模型贴地修复（浮空）

**根因**：`TrashSpawner.SpawnCore` 用固定值 `height = Large ? 0.28 : 0.18` 当作「pivot 到球面」距离，
但每件垃圾的实际半高完全对不上：轮胎 0.22、金属设备 0.225、废旧电器 0.275、塑料瓶 0.21、
易拉罐 0.18、果皮球半径 0.15、电池 0.17 → 有的浮 6 cm、有的反而陷地。
再叠 ±8° 随机倾斜与低模球面弦高误差（内置 Sphere 三角面中心比解析球面低 2~4 cm @R=8），
整片垃圾看起来都悬在地表上方。

**修法**（`Assets/Scripts/Gameplay/TrashSpawner.cs`）：
- 删掉固定 height，改为 `Place(..., 0f, ...)` 先按 pivot 压地表 → yaw/倾斜摆姿态 → `GroundFit()`：
  遍历所有**可见**渲染器的 `localBounds` 8 角点，经 localToWorld 投影到法线，取最低点，
  整体沿法线抬到「最低点刚好触地」，再嵌入 `GroundSink = 0.03`（吃掉低模球面弦高误差 + 防漏光缝）。
- 关键坑：描边副本（Outline，放大 1.0667 且默认 inactive）**不能**算进最低点，否则本体永远浮 6.7%。
  用 `GetComponentsInChildren<Renderer>(false)` + `r.enabled && activeInHierarchy` 双重过滤。
- `scatterTiltDegrees 8 → 5`：倾斜越大单侧翘起越明显（0.7 m 轮胎 8° 翘 5 cm），降下来更贴地。
- 弹出动画无需改：中途位置在地表下，缩放锚点在中心也不会露出悬空。

## 中转站 UI 文字发糊：定位与修复

### 根因（三条，不是 bug）
1. 字号过小：中文正文 11–13px、辅助 9–10px，CJK 13px 以下笔画仅 1px + 灰度 AA，本身即糊。
2. 对比度低：TextDim 0.58 压在 #1F1C19 上约 3.5:1。
3. 内置 LegacyRuntime.ttf 无中文字形，中文靠系统字体回退；且 uGUI Text 按 fontSize 光栅化后由
   Canvas 缩放重采样，只有 Game 视图 = 1920×1080（scaleFactor 1.0）才是逐像素 1:1。

### 改法
- `StationUiBuilder.cs` 只调排版参数：标题 29→32、卡片标题 16→18、英文副标 9→10、状态条 14→15、
  类别名 15→17、数量 20→22、上限 12→14、材料名 11→13、数值 19→21、单位 10→12、
  加工/制造/升级按钮 13→15、区块标题 14→16、说明 10–12→12–13；
  TextDim 0.58→0.71、TextSoft 0.79→0.875、TextStrong 0.93→0.965。
- 顺带修：材料卡「MATERIALS」副标与材料汇总行重叠 → 汇总行 y41→50、材料格子 y66→74/158。
- 新增 `Assets/Scripts/Editor/UiFont.cs`：优先用 `Assets/Art/Fonts/` 下任意 ttf/otf，否则退回内置；
  两个构建器的 LoadFont 都改走它（换字体不必改代码）。
