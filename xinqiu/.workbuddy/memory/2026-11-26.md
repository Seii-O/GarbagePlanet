# 2026-11-26

## 修复：封面右上角设置图标点击无反应

- **现象**：Play 后点 Title 场景右上角齿轮，设置面板不弹出、没有任何反应。
- **根因**：提交 `e4783a4 完善内容`（03:32）改 `Assets/Scenes/Title.unity` 时，
  把设置图标按钮 `Button (Legacy) (1)`（GO 1165006231，位置 842/412，
  onClick = `SetActive(bool=1)`）的持久化 `m_Target` 从 `GameSettingUI`(792132042)
  清成 `{fileID: 0}`；同一提交还把 TitleController 的 `sfxSlider`/`musicSlider`
  引用清成 0。旧逻辑靠场景持久化 SetActive 直接打开面板；新版
  `TitleController.BindSettingsButtons()` 只接管"目标指向 GameSettingUI"的按钮，
  目标为空时既不接管也没有兜底 → 按钮变成彻底的空绑定，Unity 静默忽略。
- **修复**：
  - `Title.unity`：恢复 `m_Target`=792132042；恢复 `sfxSlider`=612447465 /
    `musicSlider`=66159240（Slider 组件，onValueChanged 分别接 SetSfxVolume/SetMusicVolume）。
  - `TitleController.cs`：
    * `BindSettingsButtons()` 现在把 target 为 null 的 SetActive 按钮也识别为设置开关
      并接管（面板外→`OpenSettings`，面板内→`CloseSettings`），对引用丢失自愈；
      每个按钮只接管一次，不重复 AddListener。
    * 新增 `ResolveVolumeSliders()`：引用为空时按 Slider.onValueChanged 的持久化
      回调名找回滑块，保证音量页签与音量恢复不失效。
    * `OpenSettings()` 加"已打开设置面板"日志与找不到 GameSettingUI 的 Warning。
- **项目约定**：Title 场景按钮靠"子 Text 文字"由 `Assets/Scripts/Editor/TitleBuilder.cs`
  （菜单⑭）接线；设置/显隐类按钮不由 Builder 接线，靠场景持久化绑定 +
  TitleController 运行时接管。红线：Builder 不手写 .unity YAML（本次仅恢复被误清空的引用）。
- **验证**：Unity 编辑器当时正运行（Unity.exe PID 24908）。需停止 Play → 等脚本重编译
  → 重新加载/打开 Title 场景 → 再运行；Console 应出现 `[TitleController] 已打开设置面板`。
  即使场景改动被编辑器内存覆盖，代码兜底仍可让按钮生效。
