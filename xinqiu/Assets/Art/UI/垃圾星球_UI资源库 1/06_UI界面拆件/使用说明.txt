垃圾星球 UI 拆件库 · 使用说明
====================================

组织
  共 119 件。00_拆件总览.png 是全部构件的标注索引图（文件名 + 尺寸），找件看它最快。
  01–09 分类文件夹：01 面板容器 13 · 02 按钮 12 · 03 页签标签 15 · 04 进度数值 12 ·
  05 格子 7 · 06 图标_材料与成品 8 · 07 图标_功能 38（深/白双套）· 08 HUD 4 · 09 徽章装饰 10。
  全部透明底 PNG、1x 尺寸，可直接导入 Unity 作 Sprite。
  文件名即语义：pn_=面板容器 bt_=按钮 cp_=页签标签 pg_=进度 ct_=格子 ic_=图标 hud_=HUD de_=装饰。

去文字化原则
  所有底板（按钮/页签/徽章/标牌/提示条/耐久框）均不含文字，
  文字用 TextMeshPro 叠加渲染；图标内的图形符号（关闭×、加减等）已烤入，不需要动态改。

按钮状态
  普通：bt_主按钮 / bt_次按钮 / bt_危险按钮 / bt_幽灵按钮
  按下：bt_主按钮_按下 / bt_次按钮_按下（换 Sprite 即可，或用色调 tint）
  禁用：bt_禁用按钮；小尺寸：bt_小按钮_主 / _次 / _幽灵

进度条组装
  底槽 pg_进度条_底（九宫格拉伸）+ 填充 pg_填充_琥珀/青色/红色/绿色
  填充不要切九宫格，设 Image.type=Filled → Horizontal，Fill Amount 控制进度。
  pg_滑块圆钮 叠在填充末端（可选）。进度环：pg_进度环_底 + pg_进度环_青/琥珀 叠放。

容量表达（优先于长条）
  背包/仓库等「格数容量」不再用长条：主用 TMP 数字「4 / 10」，
  辅以 pg_容量点_实心 / pg_容量点_空心 按格数排成一行（实心=占用，空心=空余），
  满载时把实心点 tint 成砖红 #D2705A。百分比类（生态/耐久/修复）用圆环：
  pg_进度环_底 + 填充环，Image.type=Filled → Radial 360，或直接环形 Sprite + TMP 百分比。
  长条只保留给「正在进行的加工/修复计时」，不要用于静态容量。

格子状态
  普通 / 选中（青描边）/ 高亮（青底填充，表示当前操作格）/ 空（虚线）/ 锁定。
  格子底板九宫格拉伸，图标（01_垃圾图标_八种 或 06_图标_材料与成品）单独叠放，
  数量角标 cp_数量角标底 + TMP 数字叠右下角。

九宫格参数
  见同目录 九宫格参数.json，键为相对路径，值为 [左, 上, 右, 下]（像素）。
  未列出的件不切九宫格：图标、准星、状态点、进度环、滑块、奖章、贴纸、色条。

功能图标双色
  ic_功能_*（深棕 #4E3B27，用于浅色面板）与 ic_功能_*_白（奶白，用于深色场景叠加）。
